# Security

LocalDoc Markdown processes local files with the permissions of the user running the app.

## Recommendations

- Do not process untrusted files on machines with sensitive data.
- Keep Python dependencies, Tesseract OCR, and Windows updated.
- Review generated Markdown before publishing it.
- Avoid committing converted documents that may contain private information.

## Reporting Issues

For public reports, open a GitHub issue with reproduction steps and affected file type. For sensitive reports, contact the repository owner privately.
