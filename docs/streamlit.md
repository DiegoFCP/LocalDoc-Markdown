# App Streamlit

## Ejecutar

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Run-Streamlit.ps1
```

Abrir:

```text
http://127.0.0.1:8501
```

## Funciones

- Subir uno o varios documentos.
- Convertir a Markdown.
- Descargar resultados.
- Ver preview del Markdown.
- Ejecutar el pipeline por carpetas.
- Revisar historial y manifest.

Deja abierta la consola mientras uses Streamlit.
